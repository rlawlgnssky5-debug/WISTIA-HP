## 범위와 한계

- 검수 브라우저는 OS 움직임 감소 환경이다, 폴더 모션의 실제 일반 모드 프레임은 확인하지 않았으며 CSS 순차 지연과 모션 감소 예외를 회귀 시험으로 확인했다
- 과정 작업 사진 일부는 기존 설명용 생성 이미지다, 실제 현장 사진이라고 주장하지 않으며 원본과 제작 영상 장면을 구분하여 안내한다
- 운영 광고 수신·원격 배포는 검수 대상이 아니며, 가격·납기·혜택·추적 소스는 변경하지 않았다
