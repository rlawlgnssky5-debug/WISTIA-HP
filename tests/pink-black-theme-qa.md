# 핑크 · 블랙 · 그레이 색상 시안 검수

## 범위

- 최신 요청의 `#FF4F9A` · `#171717` · `#F5F5F5`를 전역 UI에 적용
- 핑크: 주요 버튼, POINT 강조, 상품 번호, 선택 상태, 가격 강조, 재생 진행
- 블랙: 제목, 본문, 메뉴, 홈 가격 안내 패널, 입체 받침
- 그레이: 페이지 바탕, 질문 카드, 보조 버튼, 상세 패널
- 세 기본색의 투명도를 사용한 옅은 핑크와 중성 테두리·그림자 포함
- 사진·영상·지도·로고·기존 이미지 자산의 원본 색상과 카카오톡 고유 노란색은 보존
- 기존 글꼴·배치·크기·간격·모션·문구·가격·할인·페이백 계산·상담 경로 보존
- 빠른 견적을 다시 추가하지 않았으며 문의 하단의 기존 두 상담 버튼 유지

## 구현

- 마지막 스타일시트 `css/pink-black-theme.css`, HTML의 `data-wistia-theme="pink-black"`로 범위를 한정
- 본래 스타일 파일을 덮어쓰지 않고 새 색상 계층으로 변경
- 캔버스 파형은 CSS 변수에서 색상을 읽도록 수정, 파형 모양·오디오·타임라인 로직은 변경하지 않음
- 보정 전 선택은 블랙/그레이, 보정 후 선택은 핑크/블랙으로 구분
- 갤러리의 44px 터치 영역은 투명하게 유지하고 실제 10px 점만 핑크로 표시
- 브라우저 테마색 변경 뒤에도 noindex가 유지되도록 정적 생성기의 메타 삽입을 색상 값과 독립적으로 수정
- 정적 HTML 27개 재생성, 테마/파형 캐시는 `20261005-pink-black-preview-1`

## 실제 브라우저 검수

Codex 브라우저의 `http://localhost:4174`에서 실시, 휴대폰 실기 검수 아님

- 14개 경로 × 320·390·1022px = 42개 조합
- 경로: 홈, SOLO, DUET, 스토리 필름 상세, 직접 문의, 세 상품 문의, 오시는 길, 소개, 이벤트, FAQ, 진행 안내, 보정 전후
- 페이지 가로 넘침 0
- 검사한 h1·h2·h3·문의 버튼·상품 링크·POINT 라벨 내부 가로 잘림 0
- 로딩 완료 이미지 중 깨진 이미지 0
- 42개 조합 모두 테마 속성 반영 및 바탕 `rgb(245,245,245)` 확인
- 390px 필수 성함 누락 팝업의 이유·수정 버튼·양식 없는 상담 링크 확인
- 수정 버튼 클릭 후 `contact-name` 초점 복귀 확인
- 시험 이름 `색상 시안 검수` 정상 복사와 실제 클립보드 SOLO 기본 가격/결제 예상 금액 120,000원 확인, 시험 성함은 검수 후 비움
- 카카오톡 이동 버튼은 실행하지 않음, 이번 검수에서 외부 채널 이동·메시지 전송 없음
- 390px 메뉴의 블랙 바탕·그레이 항목·핑크 그룹 라벨 확인
- 보정 후 선택의 핑크 바탕/블랙 글씨, 보정 전 선택의 블랙 바탕/그레이 글씨 확인
- 보정 후 실제 재생 시간 0.192 → 19.210초 진행, 일시정지·보정 전 전환 및 재정지 확인
- 검수 탭 오류·경고 0
- WCAG 계산식의 색상 대비: 블랙/핑크 5.84:1, 블랙/그레이 16.44:1

## 자동 검수

- 직접 실행 회귀 검사 33개 통과
