# 2026-10-15 승인 이미지 복원과 5단계 문의 검수

## 작업 기준과 보존

- 최신 원격 a79f888을 fast-forward로 반영, 노션 개인 일정 마감 및 서버 코드는 변경하지 않음
- 기존 미커밋 QA 두 문서와 최상위 과거 작업본은 보존, 이번 배포에 관련 없는 파일은 포함하지 않음
- 승인 이미지 원본 파일은 변경하지 않음, PC의 가장자리 배경만 기존 캔버스 합성 방식으로 통일
- 사진·영상·보정/AR 음원과 고객 후기 원문 유지, 후기 모달 확대 확인

## 기능

- 인원/결혼식/녹음/옵션/확인 5단계와 직접 단계 이동, 빈 날짜·시간 검증
- 유입 정확히 6개, 단일 선택 및 복사 포함
- 지난 결혼식 년/월/일 선택지 제거, 2027년 1월 31일→2월 변경 시 일 초기화, 2026년으로 변경 시 과거 월과 일 초기화
- 미정 체크 및 원래 드롭다운 복귀, 날짜 선택 즉시 ISO+요일 표시
- 녹음 달력 즉시 선택·상시 표시, 확인 버튼 없음, 과거 숫자 빈칸, 기존 마감과 1팀/2팀 표시 유지
- 시작/종료 HH:MM 표기, SOLO 60분·DUET 120분에 1절 추가 30분 적용
- 빠른 작업·두 옵션 체크 해제/선택과 금액 즉시 합산
- SOLO 전체 옵션 250,000원 / DUET 전체 옵션 290,000원
- 최종 확인과 실제 복사된 카카오 문의의 행 순서·날짜·시간·금액 일치, 총 금액 한 번, 곡/가사/페이백/기본 금액 제외
- 복사 안내 모달까지 검사, 외부 카카오 메시지는 보내지 않음

## 화면 검수

- 브라우저 확대율과 기본 viewport 설정에 차이가 있어 검수용 iframe에 정확한 CSS 폭을 지정하고 실제 내부 innerWidth로 재확인
- 360/375/390/1280/1440px 각각 5단계 직접 이동, 단계 한 줄과 검사 대상 버튼/입력/단계 이름의 가로 넘침 및 글자 잘림 0
- 같은 다섯 폭에서 SOLO↔DUET 전환 후 해당 상품정보 이미지 경로, 숨긴 표, 모바일 후기 이미지 유지/PC HTML 후기 표시 확인
- PC 두 폭의 주 섹션 너비 820px 일치, 원본 전체 비율 표시와 외곽 패널 제거
- 전체 스크롤 도구로 승인 이미지 로딩과 가로 넘침 0 확인, 숨긴 이전 HTML의 이미지 대기는 제외
- PC 재생 버튼/말풍선 중심 차이 약 0px, 말풍선 중복 안쪽 장식 제거
- AR 슬라이더 실제 너비 약 450px 확인, 모바일 말풍선은 버튼 위로 배치
- 실제 휴대폰 하드웨어 검수 및 전체 접근성 인증은 미실행
