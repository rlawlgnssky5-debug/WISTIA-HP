## 변경 범위

- 문의 양식의 native required 검사 때문에 submit 안내가 실행되지 않던 문제를 novalidate + 직접 검증으로 해결
- 필수 성함 및 일반 양식의 서비스, 활성화된 입력의 유효성을 검사하며 공백 성함도 차단
- 누락 항목명과 이유를 기존 접근성 dialog 안에 표시
- 입력 내용 수정하기 → 첫 오류 필드로 초점 복귀
- 문의 양식 없이 바로 상담할래요 → 기존 채널 href, 새 창, 안전한 rel
- 자동 복사 성공/실패의 기존 안내·가격·할인·페이백·추적 흐름 보존
- 입력 내용은 저장하거나 자동 전송하지 않음

## 로컬 검수

- SOLO 빈 성함 버튼 클릭 → 성함 입력 안내 팝업
- 공백 성함 Enter → 동일한 오류 안내
- 수정 버튼 → 성함 초점 복귀, 입력값 보존
- 정상 성함 Enter → 복사 완료 팝업, 실제 클립보드에 검수 이름 포함 확인
- 모바일 문의 320·390px → 팝업 가로 넘침 0, 두 버튼 54px 높이 및 같은 폭
- Escape → 성함 초점 복귀, 카페 유입 경로 보존
- 양식 없이 상담 버튼의 href·target·rel 확인, 이 경로는 클립보드 검수 문자열을 변경하지 않음
- 스토리 신청서 → 오류 안내 및 정상 복사, 클립보드에 스토리 필름 구성 포함
- PC 1022px → 팝업 폭 420px·내부 가로 넘침 0
- 프레임의 기존 출처 없는 MutationObserver 로그 1건, 실제 휴대폰 실기 검수 아님
