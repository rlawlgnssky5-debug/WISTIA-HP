# 2026-10-07 — SVG 제목·기능 아이콘과 섹션 정렬

## 반영 범위

- 제목에 맞는 실제 inline SVG를 생성해 제목·상품정보·기능 조작에 표시한다
- 홈의 상품·가격·사례·후기·보정·제작·FAQ·위치 제목 기준선을 통일했다
- 상품정보는 기존 dl/dt/dd와 원문·값을 보존하고 18px 아이콘·항목명·상세 내용을 분리했다
- 재생/일시정지 SVG 쌍은 DOM에 계속 유지하고 aria-pressed와 같은 상태에 따라 표시한다
- 보정 전후 전환은 두 음원과 겹치지 않는 독립 버튼이며 전환 대상 접근성 이름도 동기화한다
- AR 비율은 native range, 밝은 트랙, 테두리 있는 SVG 그립, 좌우 조작 안내로 표시한다
- 메뉴·닫기·이동·외부 링크·펼침·문의 복사 상태의 기능 문자 기호를 SVG로 정돈했다
- 실제 사진·영상·16개 후기·실제 가사 예시·브랜드·승인 대형 3D·방송 입체 타이포는 교체하지 않았다
- 가격 계산·후기 페이백 지급 조건·이름 없는 문의·빠른 작업 안내 조건은 보존한다

## 확인 결과

- 직접 회귀 57/57 및 변경한 JS 5개 구문 검사를 통과했다
- 브라우저의 실제 25개 활성 경로 × 320·390·1022px, 75개 조합에서 가로 넘침과 검사 대상 제목·설명·상품정보의 자체 잘림 0을 확인했다
- 홈 1022px의 9개 주요 제목은 아이콘 x48px, 제목 x94px로 일치한다
- 320px 상품정보의 포함 작업 문구는 글자 크기를 줄이지 않고 자연스럽게 줄바꿈하며 여섯 항목 자체 잘림 0이다
- 모든 검사 상품 상세의 혜택가는 rgb(198,40,40), 실제 후기 16장, SOLO/DUET의 가사 예시는 상세와 문의에서 전체 16:9로 표시된다
- 보정 플레이어의 실제 재생·일시정지 SVG 표시와 전후 음원 전환, 재생 위치 유지 및 전환 대상 접근성 이름을 확인했다
- AR의 실제 재생 SVG/글자 전환, 70→71→70% 키보드 비율 조작, 밝은 그립의 실제 모습을 확인했다
- 390px 보정 버튼은 최소 44px이며 전환은 독립된 3열의 가운데 자리를 사용한다
- 할인/tag 및 후기 페이백/refund SVG를 320·390px에서 펼쳐 확인했으며 카드 넘침·항목 잘림 0이다
- 메뉴의 열기/menu→닫기/close→열기 왕복을 확인했다
- 실제 후기 190px 수동 드래그 왕복은 0→-190→0px이며 자동 이동 개입 없이 복귀했다
- 별도 프로세스가 필요한 desktop-layout 대신 실제 앱 브라우저의 반응형 검수를 사용했다
