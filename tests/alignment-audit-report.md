# 전체 정렬·오시는 길 검수 보고서

폐하, 홈·AR 축가 1인과 2인·스토리 필름·오시는 길의 틀어짐을 점검하고 확인된 홈 정렬 오류를 수정하였나이다

## 확인된 오류와 수정

- 홈의 승인된 모바일 중앙 정렬이 넓은 화면에서는 유지되지 않고 제목·상단 설명·소개문이 좌측 정렬로 돌아갔사옵니다
- 소개문은 최대 너비 600px 제한과 좌측 기본 마진 때문에 898px 검사 화면에서 영역의 중심이 전체 본문 중심보다 약 92.55px 왼쪽에 위치하였사옵니다
- 홈 소개 영역에 모든 화면 폭에서 한 열·중앙 정렬·좌우 자동 마진을 명시하였나이다, 600px 소개문 및 900px 제목 상한은 보존하였나이다
- 수정 후 상단 브랜드 설명·소개 문구·제목·본문의 중심 차이는 검사한 모든 폭에서 0px이었사옵니다
- 화면 기준은 브라우저 스크롤바를 제외한 실제 본문 중심이옵니다, 스크롤바 폭을 정렬 오류로 계산하지 않았사옵니다
- 원래 왼쪽 정렬인 상품정보·인원 선택·주소 설명과 PC의 지도/주소 두 열 배치는 정상 구조이므로 임의로 중앙 정렬하거나 재설계하지 않았사옵니다
