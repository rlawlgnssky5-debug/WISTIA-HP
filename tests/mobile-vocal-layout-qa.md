# 2026-10-02 모바일 보컬 비교 수정

- 홈의 공유 플레이어에 모바일 1열 규칙이 없었음
- 기존 1열 규칙이 `solo-detail` 컨테이너와 `.before-after-page`에만 적용되어 홈에서는 PC 2열이 유지됨
- `overflow:hidden` 때문에 문서 가로 넘침 검사만으로는 내부의 시간·버튼 잘림을 잡지 못했음
- 홈 모바일 1열, 본문 14px, 제목 26px, 시간 nowrap, 선택 버튼 균등 2열 적용
- 모바일에서 플레이어가 보이는 동안 떠 있는 견적·문의 버튼을 숨기고, 벗어나거나 페이지가 바뀌면 복귀함
- 음원·가격·상담 복사 로직은 변경하지 않음

## 실제 브라우저 확인

- 홈, AR SOLO, AR DUET, 스토리 필름, 별도 보컬 비교 페이지
- iframe 외곽 폭 306 / 320 / 360 / 390 / 430 / 768 / 1440px, 총 35개 조합
- 이 PC 브라우저의 스크롤바 예약 폭이 30px이므로 실제 콘텐츠 폭은 각각 276 / 290 / 330 / 360 / 400 / 738 / 1410px로 측정됨
- 전체 문서 가로 넘침 0, 플레이어 시간·배지·선택 버튼 자체 넘침 0, 플레이어 본문 밖 잘림 0
- 홈 1440px에서 PC 2열 유지, 작은 화면에서 1열 적용
- 홈 390px 프레임에서 재생, 보정 후 선택, 일시정지, 전후 전환 확인
- 플레이어 위치에서 떠 있는 버튼 숨김, 홈 상단 이동 후 재표시 확인
- 브라우저 검수 도구의 iframe 탐색 중 MutationObserver 오류 3건이 기록됨, 홈페이지 소스에는 MutationObserver 사용이 없음
- JavaScript 구문 검사와 12개 Node 회귀 테스트 통과
- 로컬 수정이며 운영 배포는 새 승인 대기
