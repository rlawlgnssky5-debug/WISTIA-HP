## 시각 효과와 검증 범위

- 한 번 650ms 등장, 시작 opacity 0.65/아래 12px → 완료 opacity 1/기준 위치
- 둘째/셋째 80/160ms 지연, desktop hover 4px 올림, 자연스러운 얕은 그림자
- 무한 반복·큰 회전·포인터 추종·자동 영상 재생은 추가하지 않음
- 이미지가 JavaScript 로딩 전에도 보이며 고정 콜라주 비율로 이미지 로딩 후 높이 변동을 방지
- 현재 검수 브라우저 `prefers-reduced-motion: reduce`가 true
- localhost 모션 off, 127.0.0.1 모션 on 모두 실제 계산 스타일 animation none/transform none/opacity 1 확인
- 움직임 감소 조건을 우선 적용한 실제 정지 상태는 검증했으나 일반 모션 환경의 실제 애니메이션 재생·hover 움직임은 검증하지 않음
- 일반 모션의 이름/시간/시작/완료/지연/hover/감소 조건은 새 회귀 시험으로 검사
- 휴대폰 실기·일반 모션 실기·외부 상담 전송은 수행하지 않음
