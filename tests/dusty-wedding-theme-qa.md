# 더스티 핑크 · 베이지 · 브라운 시안

## 색상 역할과 디자인

- Primary: `#EFA8B8` 더스티 핑크, 홈 첫 화면·상담 소개·선택 상태·핵심 브랜드 면
- Secondary / background: `#EFE3D5` 베이지, 페이지 바탕·보조 버튼·카드 사이 여백
- Accent: `#7B625B` 브라운, 주요 상담 버튼·메뉴·가격 안내 패널
- Neutral: `#FBF8F4` 아이보리, 카드·팝업·브라운 위 글씨
- Readable ink: `#3C302C` 진한 브라운, 본문·작은 라벨·핑크 위 글씨
- 브랜드 브라운/핑크의 대비는 2.93:1, 브라운/베이지는 4.44:1이므로 작은 글씨에 그대로 사용하지 않음
- 실제 사용 대비: 브라운/아이보리 5.30:1, 진한 브라운/핑크 6.64:1, 진한 브라운/베이지 10.06:1

첨부에서 요청한 면 중심의 둥근 박스 인상을 반영

- 홈 첫 화면은 큰 핑크 면과 36px 모서리, 웹에서는 44px 모서리
- 상품은 아이보리 28px 모서리 카드, 상품 링크는 베이지 알약형 버튼 표현
- 굵은 외곽선과 딱딱한 단차 받침 제거, 가격 안내는 브라운 32px 둥근 패널
- POINT는 큰 채움 배지 대신 가벼운 라벨로 구분, 번호와 문구 자체는 보존
- 질문별 카드는 24px 모서리, 상담 소개는 핑크 28px 카드, 고정 상담 버튼은 20px 모서리
- 사진·영상·지도·원본 로고·카카오톡 고유 노란색은 유지
- 상품·문구·가격·혜택 계산·필수 검증·복사·상담 연결·기존 터치 영역은 보존

## 구현

- 이전 팔레트 파일은 공통 색상 기반으로 범위를 일반화하고 보존
- 활성 테마는 `data-wistia-theme="dusty-wedding"`, 마지막 계층은 `css/dusty-wedding-theme.css`
- 캐시 `20261005-dusty-wedding-preview-1`, 브라우저 테마색 베이지
- 정적 HTML 27개 재생성, 기존 noindex 유지
- 이번 변경에서 상품 렌더러·가격 계산·문의 JavaScript를 수정하지 않음
- 카드 구조는 실제 링크/입력/버튼을 유지, 장식으로 비활성화하거나 가린 동작 없음

## 브라우저 검수

Codex 브라우저 `http://localhost:4174`, 실제 휴대폰/카카오 인앱 실기 검수는 아님

- 14개 경로 × 320·390·691·1022px = 56개 조합
- 홈, SOLO/DUET/스토리 상세, 직접 문의, 세 상품 신청서, 오시는 길, 소개, 이벤트, FAQ, 진행 안내, 보정 전후
- 루트 가로 넘침 0, 검사한 제목/문의 버튼/상품 링크/POINT 내부 가로 잘림 0
- 로딩 완료 이미지 중 깨진 이미지 0, 56개 조합 모두 새 테마 반영
- 검사한 페이지 배경에 이전 네온 핑크 `rgb(255,79,154)` 잔존 없음
- 1022px 홈 제목 중심축 차이 0px, 실제 두 열 상품 카드와 둥근 버튼 확인
- 390px 질문별 카드가 베이지 바탕에서 개별 분리되는 실제 화면 확인
- 390px 고정 상담 두 버튼의 실제 계산된 20px 모서리와 브라운/아이보리 대비 확인
- 빈 성함 버튼 클릭 → 필수 안내 팝업 → 수정 버튼 → `contact-name` 초점 복귀 확인
- 스토리 필름의 시험 성함 `디자인 검수` 정상 복사, 실제 클립보드 기본/결제 예상 금액 350,000원 확인, 검수 후 시험 성함 비움
- 보정 후 실제 재생 0.170 → 28.650초 진행, 일시정지와 보정 전 전환·재정지 확인
- 보정 후 핑크/진한 브라운, 보정 전 브라운/아이보리의 실제 선택 색상 확인
- 마지막 검수 탭 오류/경고 0
- 외부 카카오톡 이동·상담 메시지 전송은 수행하지 않음
