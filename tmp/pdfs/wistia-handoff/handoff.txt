INFORMATION ARCHITECTURE
사이트맵 + 유저플로우
Vanilla JS 해시 라우팅 SPA. route() 가 location.hash 를 파싱해 #app 에 렌더. MENU = [] 이라 헤더 내비는 없음.
해시 라우트 렌더러 목적
#/ renderHome 상황 선택 홈 「저는 지금,」
#/film renderPicker("film") 축가 영상 피커 (듀엣/솔로 필름)
#/song renderPicker("song") 축가 녹음 피커 (솔로/2인) — 홈 직접 링크 없음
#/ar/self renderArPurpose("self") 본인 결혼식 축가 AR
#/ar/friend renderArPurpose("friend") 지인 결혼식 축가 AR
#/detail/{product} renderDetail 상품 상세. wedding, duet-film, solo-film, proposal, solo, duo
#/detail/{product}/{format} renderDetail format(live/making) 가능 — 상세 UI는 format 미반영
#/choose/{filmProduct} renderDetail 필름 상세 별칭. 포맷 선택 UI 없음
#/event/{product} renderEvent 구성·가격·옵션·이벤트·상담 폼
#/event/{product}/{format} renderEvent 필름 live/making 초기값. solo+friend = 지인 옵션
#/event/solo/friend renderEvent("solo","friend") AR friend 플로우 가격바 목적지
#/section/{id} home + scroll MENU 비어 있어 사실상 미사용
(미매칭) 인라인 404 찾으시는 페이지가 없습니다 → 홈
상황 분기 플로우
홈(#/)
├─ 식전 영상 → detail/wedding → event/wedding[/live|making] → 카카오 상담
├─ 축가 영상 → film picker → detail/duet-film | solo-film → event/… → 카카오
├─ 프로포즈 → detail/proposal → event/proposal → 카카오
├─ 본인 축가 AR → ar/self → (비율 체험)
│ → detail/solo | duo 또는 priceBar → event/solo → 카카오
├─ 지인 축가 AR → ar/friend → … → event/solo/friend → 카카오
└─ 신랑신부 함께 → detail/duo → event/duo → 카카오
병렬: 헤더「예약 상담」 / 푸터 카카오 / 플로팅 카카오 → 즉시 카카오 (폼 없이)
