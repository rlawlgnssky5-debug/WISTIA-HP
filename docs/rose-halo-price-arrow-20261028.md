# 로즈 헤일로 및 모바일 할인 화살표

- 승인된 로즈 헤일로 시안을 고민 영역에 적용
- 기존 회색은 섹션뿐 아니라 ::before 전체 너비 배경에도 남아 있었으므로 두 페인트 레이어를 함께 교체
- 흰 바탕과 오른쪽 위·왼쪽 아래 장미색 빛 번짐, 승인한 말풍선 색상을 사용
- 고민 문구·순서·본문 780px·가격·할인 조건·티켓·추적 코드 보존
- 세 가격 행의 DOWN 문구를 같은 절약액과 ↓ 표시로 교체
- 배지는 줄바꿈하지 않고 안내 문구 옆에 고정, 아주 좁은 화면에서 긴 안내 문구만 줄바꿈
- 스크린리더에는 동일 금액의 할인으로 안내
- 303px를 검수 너비에 추가하여 작은 실제 화면과 유사한 환경 포함
- 배지의 아래 줄 이동을 허용하던 이전 테스트를 제거하고 모든 너비에서 문구 옆 위치를 필수 검증
- 회색 덮개 재발 방지를 위해 실제 ::before의 배경도 검사
- 원본 시안·사진·미디어는 삭제하지 않음
- 문의 제출·카카오 열기·예약 데이터 변경 없이 검수
