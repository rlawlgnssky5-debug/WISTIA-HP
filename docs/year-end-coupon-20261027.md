# 연말 방문 할인 쿠폰 변경

## 확정 기준

- 기준 main: 3dfa08d (Round 45)
- 명칭: 연말 방문 할인 쿠폰
- 녹음 날짜가 2026년이며 2026-12-31 이하인 경우에만 20,000원 할인
- 적용 상품: DELUXE·PREMIUM·DUET, STANDARD 제외
- 첫 이용 20,000원·사전 예약·목금 시간 할인과 중복 적용, 기존 금액과 상품 구성은 유지
- 2027-01-01 00:00 한국 시간에 종료, 열린 화면과 복귀한 탭에서도 제거
- 녹음 날짜가 미정이거나 잘못된 값, 지난 날짜, 2027년 날짜이면 차감하지 않음
- 문의 첫 단계의 쿠폰 선택은 날짜 선택 전 보관하며 실제 차감은 날짜를 선택한 뒤 계산
- 선택한 날짜가 2027년으로 바뀌면 차감을 해제하고 2026년으로 돌아오면 선택한 쿠폰을 재적용

## 변경 파일과 범위

- js/package-pricing.js: 공통 쿠폰 조건·할인 이름·조건부 상품 표시가·최대 할인 계산·연말 선물 카드·자동 종료
- js/booking-wizard.js: 쿠폰 선택·조건 안내·상품과 날짜 변경에 따른 재계산
- js/booking-draft.js: 새 쿠폰 선택값 보존, 과거 10월 쿠폰 선택은 새 쿠폰으로 임의 전환하지 않음
- js/app.js: 이벤트·상세의 쿠폰 이름과 조건, 연말 선물 카드 연결
- css/canvas-780.css: 새 쿠폰 선택자와 한 줄 문구 조정, 다른 영역의 색과 배치 보존
- 공개 HTML 8개: 변경한 공통 자원의 캐시 버전 갱신
- tests/package-pricing.test.mjs: 날짜·상품·중복 할인·만료·과거 쿠폰 회귀
- tests/year-end-coupon-browser.cjs: 360·375·390·414·1280px 공개 페이지, 날짜 전환·초안·만료 검수

## 검수 방식

- 실제 Edge의 모바일 화면 에뮬레이션과 PC 780px 본문 검수, 실물 휴대폰 검수는 아님
- 2026-10-27 한국 시간을 고정하여 2026-12-31과 2027-01-02 계산을 비교
- 예: DELUXE 170,000원, 첫 이용 선택 및 목요일 2026-12-31 13시 선택 시 연말 20,000원 + 첫 이용 20,000원 + 사전 예약 20,000원 + 시간대 10,000원으로 100,000원
- 예: 같은 상품과 첫 이용 선택으로 2027-01-02 13시 선택 시 첫 이용 20,000원 + 사전 예약 20,000원으로 130,000원
- 실제 문의 제출·카카오 열기·예약 생성은 실행하지 않음
- 예약 가능 시간은 브라우저 검수에서만 빈 일정 fixture 사용, 운영 예약 데이터 변경 없음
- GA4·메타 픽셀과 문의 전송 트리거를 수정하지 않음
- 검색 제목·설명과 운영 JS 전체를 검색하여 과거 10월 쿠폰 및 11월 1일 만료 조건 제거 확인
- 배포는 PR 미리보기 확인 후 main 병합, 운영 공개 경로와 변경 자원 확인
- 운영 HTTP 500 발생 시 이번 병합을 되돌리고 재배포 확인

검수 증빙은 output/year-end-coupon-20261027 아래 로컬 보관

## 2026-10-27 검수 및 배포 상태

- 가격·달력·초안 관련 단위 회귀 26건 통과
- 로컬 Edge 브라우저 5개 너비의 100개 확인 항목 통과, 페이지 오류 없음
- 변경은 PR #102에 보관, Vercel 미리보기 빌드 성공
- 미리보기 접속은 Vercel 로그인으로 리다이렉트되어 실제 배포 화면 검수 불가
- 미리보기의 로그인 화면에서 발생한 외부 POST는 테스트 안전 장치가 차단, 문의 제출이나 카카오 열기 실행 없음
- 로그인 없이 접근 가능한 승인된 미리보기 공유 링크가 필요
- 미리보기 확인 후 병합이라는 요청 순서를 지키기 위해 main 병합과 운영 배포는 보류
- 운영 오류나 롤백이 발생한 상태는 아님, 운영은 기존 버전 유지
