# 승인 쿠폰 받기·선택 연동 배포

- 승인된 안내 화살표형 사용, 버튼의 아래 화살표는 표시하지 않음
- 쿠폰 받기 줄 높이 55px, 누르는 버튼은 최소 44px 유지
- 메인·상세의 첫 이용 및 연말 쿠폰에 받기 버튼 추가
- 문의의 쿠폰 선택도 같은 디자인으로 통일, 중복 방문 조건 하단 문구 제거
- 받으면 장미·골드 파티클 36개가 두 번의 짧은 파동으로 터지고 1.45초 후 제거
- 동작 줄이기 설정에서는 파티클 생성과 애니메이션을 모두 생략
- 선택 상태는 개인정보 없는 전용 키에 3시간 보관, 첫 이용·연말 쿠폰 두 boolean과 저장 시각만 저장
- 메인→문의·직접 접속·새로고침·뒤로가기·다른 탭에서 선택 및 해제를 공유
- 저장소가 제한된 브라우저에서는 같은 SPA 이동 동안 메모리로 연동
- 기존 문의 초안의 상품·옵션·일정·특이사항을 덮어쓰지 않고 쿠폰 필드만 공유
- 스탠다드는 연말 쿠폰을 할인하지 않으며, 받아 둔 쿠폰은 대상 상품으로 바꿀 때 선택 복원
- 연말 쿠폰 실제 할인은 기존 대상 상품·2026년 11~12월 녹음 날짜·종료 시각 기준을 그대로 따름
- 2027년 1월 1일 한국 시간 0시에 연말 카드와 받기 버튼 전체 제거
- 가격·타입·할인액·파티클 외 기존 효과·티켓·로즈 헤일로·780px·분석·문의 전송 경로 유지
- 개인정보를 분석 도구로 보내지 않으며 쿠폰 선택을 URL에 넣지 않음
- 문의 제출·카카오 열기·실제 예약 데이터 변경 없이 검수
