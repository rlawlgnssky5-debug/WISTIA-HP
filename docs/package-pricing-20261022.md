# 2026-10-22 패키지 개편

## 확정 구성

- A 90,000원: 1인·1곡, 녹음 1시간, 1:1 디렉팅, 기본 믹싱, 당일 음원 전달
- B 130,000원: 녹음 1시간, 보컬 튜닝과 디테일 믹싱 서비스 포함, 영업일 기준 7일 이내 전달, 개별 선택 대비 20,000원 절약
- C 170,000원: B 구성에 녹음 1시간 추가, 총 2시간, 개별 선택 대비 30,000원 절약
- 제목: 패키지로 예약하면 더 저렴해요!

## 추가 옵션

- 보컬 튜닝 40,000원, B·C 포함
- 디테일 믹싱 20,000원, B·C 서비스 포함
- 듀엣으로 변경 30,000원, 선택한 패키지의 녹음 시간 유지
- 녹음 1시간 추가 50,000원, C의 기본 2시간에 다시 추가하면 총 3시간
- 100% 립싱크를 원해요 20,000원
- 3일 이내 빠른 작업 30,000원, 제작 일정과 자료 준비 상태에 따라 상담 후 확정
- A 기본 구성은 이미 당일 전달이므로 불필요한 3일 이내 옵션 비용은 붙이지 않으며 보컬 튜닝 선택 시 활성화
- 추가 1절 녹음과 가사 영상은 노출·선택·계산·문의 문구에서 제거, 원본 파일은 보존

## 할인·페이백·서비스

- 첫 이용 10,000원
- 목·금 13:00~16:00 녹음 시작 10,000원
- 녹음일까지 한 달 이상~두 달 미만 10,000원 또는 두 달 이상 20,000원
- 날짜는 한국 시간 기준 달력상 한 달·두 달로 계산하며 월말은 해당 월 마지막 날로 보정
- 새 환급 상한이나 별도 인당 보정비를 신설하지 않음
- 블로그와 본식 현장 영상 각 30,000원 환급, 합계 60,000원, 결제 전 차감하지 않음
- 2026년 예식 30분 무료 추가는 실제 녹음 소요 시간과 예약 충돌 검사에도 반영

## 구현 범위

- `js/package-pricing.js`의 공통 모델을 상세·문의·계산·시간 안내에서 공유
- 가격과 공통 포함 작업이 인쇄된 안내 영역은 동적 HTML로 교체하고 원본 미디어는 삭제하지 않음
- 기존 테마의 고우선순위 규칙과 충돌하지 않도록 새 가격 영역만 독립 CSS 계층으로 한정
- 패키지 선택을 문의 경로와 URL에 연결하며 기존 방문자 쿼리 값을 보존
- 새 패키지·옵션·할인·페이백 선택도 기존 3시간 브라우저 초안에 저장
- 삭제한 예전 초안 옵션은 복원·가격 계산에서 제외
- 관련 FAQ, 검색 메타, 공유 설명, 구조화 가격, 숨긴 검색용 글을 새 구성으로 통일
- `node scripts/build-css-bundle.mjs`로 공통 CSS와 진입 HTML 갱신
